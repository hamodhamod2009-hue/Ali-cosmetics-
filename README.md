# Ali Cosmetics Pro v4

نسخة محدثة تشمل جميع ميزات الزبائن والمبيعات السابقة، مع قسم مستقل لحسابات التجار.

## الجديد
- إضافة ديون التجار على المحل.
- تسجيل اسم التاجر، الهاتف، المبلغ، المدفوع، المتبقي، التاريخ والاستحقاق.
- تسجيل دفعات جزئية أو كاملة للتاجر.
- تقرير مستقل لدفعات التجار حسب الفترة.
- ملخص إجمالي ديون التجار، ما دفعه المحل، والمتبقي.
- بقاء نظام الزبائن والديون والمدفوعات والتقارير كما هو.

## التشغيل
```bash
npm install
npm start
```
