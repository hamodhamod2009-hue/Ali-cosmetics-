# Ali Cosmetics Pro v5

نظام إدارة محل مستحضرات التجميل، ويشمل:

- المنتجات والمخزون
- المبيعات وفواتير الزبائن
- ديون الزبائن والمدفوعات
- شراء البضاعة من التجار مع زيادة المخزون تلقائياً
- إضافة المتبقي تلقائياً إلى حساب التاجر
- دفعات التجار وكشف حساب لكل تاجر
- كشف حساب لكل زبون
- تقارير يومية وشهرية وسنوية ومخصصة
- طباعة التقارير وكشوف الحساب
- نسخ احتياطي واسترجاع البيانات

## تشغيل المشروع

```bash
npm install
npm start
```

بيانات الدخول الافتراضية:

- المستخدم: `admin`
- كلمة المرور: `admin123`

> البيانات محفوظة في متصفح الجهاز عبر localStorage، لذلك يُنصح بتنزيل نسخة احتياطية بصورة منتظمة.
