# Ali Cosmetics — النسخة الكاملة الحالية

نسخة تشغيلية لمحل Ali Cosmetics مبنية على آخر ملفات المشروع، وتحافظ على مفتاح البيانات القديم `ali_cosmetics` حتى تبقى بيانات المتصفح عند تحديث الموقع على **نفس الرابط ونفس المتصفح**.

## الوظائف الموجودة
- المنتجات والمخزون، مع براند اختياري وكود/باركود وتصنيف وحد تنبيه للمخزون.
- سعر بيع منفصل لزبون المحل وزبون التاجر.
- شراء البضاعة من التجار وتحديث المخزون تلقائياً.
- رقم فاتورة التاجر والبحث بالاسم/المنتج/رقم الفاتورة.
- دفعات جزئية للتاجر وتحديث المدفوع والمتبقي في فاتورة الشراء وحساب التاجر معاً.
- مبيعات زبون محل وزبون تاجر وفواتير مرقمة تلقائياً.
- دفعات جزئية للزبائن، وقائمة ديون تبين نوع الزبون وتاريخ الاستحقاق.
- سجل المدفوعات وكشوف حساب الزبائن والتجار.
- تقارير المبيعات والتكلفة والربح والمبالغ المستلمة والمتبقية.
- حسابات عمال وصلاحيات مستقلة للأقسام وتعديل الأسعار والحذف.
- IQD كعملة افتراضية، مع USD وAUD كخيارات إضافية.
- حفظ تلقائي محلي لآخر 10 تغييرات + تنزيل/استرجاع نسخة JSON يدوية.

## التشغيل على الكمبيوتر
يتطلب Node.js 18 أو أحدث فقط، ولا يحتاج `npm install` ولا مكتبات خارجية.

1. فك ضغط الملف.
2. افتح Terminal / Command Prompt داخل المجلد.
3. شغّل: `npm start` أو `node server.js`.
4. افتح المتصفح على: `http://localhost:3000`.

على Windows يمكنك أيضاً الضغط مرتين على `START-WINDOWS.bat`.

## بيانات الدخول الافتراضية
- المدير: `admin` / `admin123`
- العامل التجريبي: `employee` / `1234`

من قسم **المستخدمون والصلاحيات** يقدر المدير ينشئ حسابات عمال ويحدد صلاحيات كل حساب.

## النسخ الاحتياطية
بيانات هذه النسخة مخزنة في `localStorage` داخل المتصفح. الحفظ التلقائي المحلي يحمي من بعض الأخطاء داخل نفس المتصفح، لكنه **ليس نسخة خارجية**. استخدم زر **تنزيل نسخة احتياطية** بانتظام لحفظ ملف JSON خارج المتصفح.

إذا تم تغيير الدومين/الرابط أو المتصفح أو الجهاز، البيانات لا تنتقل تلقائياً؛ صدّر نسخة JSON من الجهاز القديم ثم استرجعها في الجهاز الجديد.

## النشر
ارفع ملفات المشروع كما هي إلى GitHub/Railway أو أي استضافة تشغل Node.js. أمر التشغيل هو `npm start`. لا توجد Dependencies خارجية.

## فحص المشروع
شغّل `npm run check` لفحص JavaScript والتأكد من وجود الوظائف الأساسية.

## ملاحظة أمنية مهمة
نظام الصلاحيات الحالي مناسب لتنظيم استخدام العمال داخل واجهة البرنامج، لكن البيانات والحسابات محفوظة في المتصفح وليست نظام مصادقة خادمي عالي الأمان. إذا احتجت لاحقاً استخداماً من أجهزة متعددة مع قاعدة بيانات مركزية ومزامنة وحماية خادمية، فهذا يتطلب مرحلة Backend/Database منفصلة.
