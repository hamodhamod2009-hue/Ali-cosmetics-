# Ali Cosmetics Pro v7

نظام إدارة محل مستحضرات تجميل بواجهة عربية وإنجليزية.

## الجديد في v7

- تبديل كامل بين العربية والإنجليزية مع RTL / LTR.
- تنظيم المنتجات: البراند ثم التصنيف ثم الآيتم.
- عدد غير محدود من الآيتمات لكل براند.
- بحث بالبراند أو اسم الآيتم أو الكود أو الباركود.
- حد تنبيه مستقل لكل آيتم وتنبيهات انخفاض المخزون في الصفحة الرئيسية.
- صلاحيتان للدخول: مدير وموظف.
- المحافظة على المبيعات والمشتريات وديون الزبائن وحسابات التجار والتقارير والطباعة والنسخ الاحتياطي.

## تسجيل الدخول

- المدير: `admin` / `admin123`
- الموظف: `employee` / `1234`

> البيانات تبقى محفوظة في متصفح الجهاز. نزّل نسخة احتياطية بانتظام.
