Ali Cosmetics Web v0.1

هذه أول حزمة تنفيذية للنسخة المستضافة:
- Node.js + Express
- SQLite database
- Session login
- Admin account
- Products: category, purchase price, sale price, quantity, currency
- Sales with automatic inventory deduction

بيانات الدخول الافتراضية:
username: admin
password: admin123

تشغيل محلي:
1. ثبّت Node.js.
2. افتح الطرفية داخل مجلد المشروع.
3. شغّل: npm install
4. شغّل: npm start
5. افتح: http://localhost:3000

للحصول على رابط يفتح من Safari على iPad، يجب نشر المشروع على خدمة استضافة. لا ترسل كلمات مرور أو مفاتيح سرية داخل المحادثة.
